Bundled stream-graphics fonts — SIL Open Font License 1.1
=========================================================

The three font files in this directory are latin-subset WOFF2 builds taken
from Google Fonts. Each is licensed under the SIL Open Font License,
Version 1.1. The full license text is available at:

    https://openfontlicense.org/open-font-license-official-text/

They are bundled (rather than loaded from a CDN) so the transparent OBS
stream output page (/stream/{slug}) renders identically offline — the
church rig has no guaranteed internet at service time. Only the latin
subset is shipped to keep each file small.
