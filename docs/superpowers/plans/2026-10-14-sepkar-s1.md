# Šepkár Tips (#852 S1a + S1b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the first two PR units of #852: **S1a** (the šepkár server — `interpreter_tips` table, repository, validation and limits, the duplicate window, five REST endpoints, `LiveEvent::InterpreterTips`, the retention + boundary task, INFO lines) and **S1b** (the šepkár page `/ui/sepkar`, the interpreter tablet page `/ui/interpreter` with its tips area — dismiss, swipe, undo, dismiss-all, highlight, resync — and the two-page Playwright spec `interpreter-tips.spec.ts`), so that tips are usable at the next guest service (milestone M-T: T-S1–T-S3).

**Architecture:** The rules live once, in a pure `presenter-core::interpreter_tips` module (DTOs, limits, cleaning, validation, "active", "duplicate") that the server and the WASM pages share. The server stores tips in a site-local table (no sync columns), decides validation and rate limits in the STATE layer (`TipRefusal` → 422 / 429 + `Retry-After`, mapped in the new router module), lets the repository refuse unknown ids (404) and other-day restores (409) through the central `RepositoryError` mapping, and publishes the FULL active list on the main live hub after every write and at the midnight / 4 h boundary. The two WASM pages read the hub through a new presence-free, per-event socket hook (`ws/passive.rs`, the #793 rule) and resync with `GET /interpreter/tips` on load and after every reconnect, dropping a resync answer that a live event overtook. The interpreter page is built as a grid with a slot per area (§8.2); only the tips area has data before C5a, so it fills the page.

**Tech Stack:** Rust 2021 (msrv 1.85), axum 0.8, SeaORM 1.1 (SQLite), tokio (test-util in dev-deps), tracing, chrono, thiserror; Leptos 0.7 CSR + gloo-net / gloo-timers + web-sys (WASM, `crates/presenter-ui`, workspace-excluded); Playwright 1.55 (TypeScript).

**Spec:** `docs/superpowers/specs/2026-10-14-sermon-listening-interpreter-assist-design.md` (commit 15d8cebb; APPROVED by the owner 2026-10-14, #852 comment "ROZHODNUTÉ … answer 1") — §2 (šepkár decision), §4 (transports), §8.1–§8.2 (page + tablet layout), §9 (šepkár), §11 (šepkár failure rows), §14 (tip log lines), §15 (šepkár tests), §16 (units S1a, S1b).

## Review Focus

The spec says what the tips must do; these five conditions it implies but does not test are the most likely to bite a šepkár or an interpreter. Each line names the test that pins it.

1. **Two quick taps, two šepkárs sending the same word, a dismissed tip sent again.** A double tap must not show two cards; a tip the interpreter just hid must be sendable again (otherwise the šepkár sees "Tento tip už tlmočník má" while the interpreter sees nothing). Tests: core `a_duplicate_is_the_same_pair_or_note_within_two_minutes_and_not_dismissed` (Task 2), router `the_same_pair_within_two_minutes_is_200_duplicate_and_no_new_row` (Task 8), E2E T-S1 duplicate step (Task 13).
2. **A tablet that slept or lost its socket while tips arrived.** The hub never replays; a resync answer that started before a newer live list must not roll the list back. Tests: UI `fetch_guard_drops_an_answer_overtaken_by_a_live_list` (Task 11), E2E `the interpreter catches up after a reload and after a lost live frame` (Task 12).
3. **Midnight, the 4 h window and a server restart mid-service.** A tip must leave the screen at the boundary even when nothing else happens, and even right after a restart. Tests: state `the_four_hour_window_empties_the_list_on_the_next_tick`, `midnight_empties_the_list_on_the_next_tick`, `a_restart_mid_service_still_sends_the_boundary_event` (Task 7).
4. **Several šepkárs behind one public IP (the Cloudflare tunnel), "Peter" vs "peter".** The name must be part of the key, its case must not; a refused or invalid tip must not use a slot. Tests: `the_name_is_part_of_the_key_and_its_case_is_not` (Task 6), router `the_sixth_tip_of_one_sender_within_a_minute_is_429_with_retry_after` and `invalid_tips_are_422_with_the_slovak_rule` (8 invalid posts from one sender, then valid ones) (Task 8).
5. **Odd text: control characters, multibyte limits, a 190-char unspaced word on a 390 px phone, HTML-looking text.** Lengths count characters, controls never reach a card, a long word wraps instead of widening the page, `<b>` renders literally. Tests: core `each_rule_has_its_own_refusal`, `exactly_at_the_limits_is_valid_counting_chars_not_bytes`, `control_characters_never_survive_cleaning` (Task 2), E2E `the šepkár page fits a phone …` (long note + literal `<b>`, Task 13) and `the tablet fits …` (Task 12).

```rust
//! Šepkár (prompter) tips for the interpreter (#852, spec §9): the DTOs the
//! server, the šepkár page and the interpreter page share, the limits, and
//! the pure rules — text cleaning, validation, which tips are active and
//! which new tip repeats a recent one. No I/O and no clock: callers pass
//! `now` and the service date, so every rule is unit-tested here.

use chrono::{DateTime, Duration, NaiveDate, Utc};
use serde::{Deserialize, Serialize};
use thiserror::Error;

/// A word or phrase as heard, and its suggested translation: 1–60 chars each.
pub const TIP_TERM_MAX_CHARS: usize = 60;
/// A free note: at most 200 chars (it fits a tablet card).
pub const TIP_NOTE_MAX_CHARS: usize = 200;
/// The sender's typed name: 1–40 chars.
pub const TIP_SENDER_MAX_CHARS: usize = 40;
/// The audit user agent is cut to this many chars.
pub const TIP_USER_AGENT_MAX_CHARS: usize = 200;
/// A tip stays on the interpreter's screen this long; it separates the
/// morning and the evening service of one day.
pub const TIP_ACTIVE_WINDOW_HOURS: i64 = 4;
/// The live event carries at most this many active tips, newest first.
pub const TIP_LIVE_LIST_CAP: usize = 20;
/// The same tip sent again within this many seconds is a duplicate.
pub const TIP_DUPLICATE_WINDOW_SECS: i64 = 120;
/// Stored tips older than this many days are deleted.
pub const TIP_RETENTION_DAYS: i64 = 30;
/// Accepted tips per (sender IP, sender name) per rate window.
pub const TIP_RATE_PER_SENDER: usize = 5;
/// Accepted tips overall per rate window.
pub const TIP_RATE_OVERALL: usize = 30;
/// The rate window, in seconds.
pub const TIP_RATE_WINDOW_SECS: u64 = 60;

/// One stored tip as every client sees it. The audit columns (`sender_ip`,
/// `user_agent`) never leave the server.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct TipDto {
    pub id: i64,
    /// The server's local date at creation, `YYYY-MM-DD`.
    pub service_date: String,
    pub source_term: Option<String>,
    pub target_term: Option<String>,
    pub note: Option<String>,
    pub sender_name: String,
    pub created_at: DateTime<Utc>,
    pub dismissed_at: Option<DateTime<Utc>>,

/// reaches validation (a Slovak 422) instead of axum's English rejection.

    pub sender_name: String,
    pub source_term: Option<String>,
    pub target_term: Option<String>,
    pub note: Option<String>,
}

pub struct ValidTip {
    pub sender_name: String,
    pub source_term: Option<String>,
    pub target_term: Option<String>,
    pub note: Option<String>,
}

#[serde(rename_all = "camelCase")]

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]

    pub duplicate: bool,

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]

/// Why a tip was refused. The text is shown to the šepkár as it is.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Error)]
pub enum TipValidationError {
    #[error("Napíš svoje meno.")]
    MissingSender,
    #[error("Meno môže mať najviac 40 znakov.")]
    SenderTooLong,
    #[error("Napíš slovo s prekladom alebo poznámku.")]
    Empty,
    #[error("Vyplň slovo aj preklad, alebo ani jedno.")]
    HalfPair,
    #[error("Slovo aj preklad môžu mať najviac 60 znakov.")]
    TermTooLong,
    #[error("Poznámka môže mať najviac 200 znakov.")]
    NoteTooLong,
}

/// Control characters become spaces, then the text is trimmed: a pasted tab,
/// newline or escape sequence never reaches a card or the log.
pub fn clean_text(raw: &str) -> String {
    let replaced: String = raw
        .chars()
        .map(|c| if c.is_control() { ' ' } else { c })
        .collect();
    replaced.trim().to_string()
}

/// The audit user agent: cleaned, cut to [`TIP_USER_AGENT_MAX_CHARS`].
pub fn clean_user_agent(raw: &str) -> Option<String> {
    let cleaned = clean_text(raw);
    if cleaned.is_empty() {
        return None;
    }
    Some(cleaned.chars().take(TIP_USER_AGENT_MAX_CHARS).collect())
}

fn cleaned(raw: Option<&str>) -> Option<String> {
    raw.map(clean_text).filter(|text| !text.is_empty())
}

fn too_long(text: Option<&str>, max: usize) -> bool {
    text.is_some_and(|text| text.chars().count() > max)
}

/// Spec §9.2 / §9.8: name 1–40, both terms (1–60 each) or neither, note
/// ≤ 200, at least a pair or a note. Lengths count characters, not bytes.
pub fn validate_tip(request: &NewTipRequest) -> Result<ValidTip, TipValidationError> {
    let sender_name = clean_text(&request.sender_name);
    if sender_name.is_empty() {
        return Err(TipValidationError::MissingSender);
    }
    if too_long(Some(sender_name.as_str()), TIP_SENDER_MAX_CHARS) {
        return Err(TipValidationError::SenderTooLong);
    }
    let source_term = cleaned(request.source_term.as_deref());
    let target_term = cleaned(request.target_term.as_deref());
    let note = cleaned(request.note.as_deref());
    if source_term.is_some() != target_term.is_some() {
        return Err(TipValidationError::HalfPair);
    }
    if source_term.is_none() && note.is_none() {
        return Err(TipValidationError::Empty);
    }
    if too_long(source_term.as_deref(), TIP_TERM_MAX_CHARS)
        || too_long(target_term.as_deref(), TIP_TERM_MAX_CHARS)
    {
        return Err(TipValidationError::TermTooLong);
    }
    if too_long(note.as_deref(), TIP_NOTE_MAX_CHARS) {
        return Err(TipValidationError::NoteTooLong);
    }
    Ok(ValidTip {
        sender_name,
        source_term,
        target_term,
        note,
    })
}

fn normalized(text: &str) -> String {
    text.to_lowercase()
        .split_whitespace()
        .collect::<Vec<_>>()
        .join(" ")
}

/// What a tip says, for the duplicate check: its pair if it has one, else
/// its note — lower-cased, whitespace collapsed.
pub fn duplicate_key(source: Option<&str>, target: Option<&str>, note: Option<&str>) -> String {
    match (source, target) {
        (Some(source), Some(target)) => {
            format!("pair\u{1f}{}\u{1f}{}", normalized(source), normalized(target))
        }
        _ => format!("note\u{1f}{}", normalized(note.unwrap_or_default())),
    }
}

fn text_chars(parts: [Option<&str>; 3]) -> usize {
    parts.iter().flatten().map(|text| text.chars().count()).sum()
}

impl ValidTip {
    pub fn duplicate_key(&self) -> String {
        duplicate_key(
            self.source_term.as_deref(),
            self.target_term.as_deref(),
            self.note.as_deref(),
        )
    }
}

impl TipDto {
    pub fn duplicate_key(&self) -> String {
        duplicate_key(
            self.source_term.as_deref(),
            self.target_term.as_deref(),
            self.note.as_deref(),
        )
    }

    /// Characters of tip text (pair + note), for the INFO line.
    pub fn chars(&self) -> usize {
        text_chars([
            self.source_term.as_deref(),
            self.target_term.as_deref(),
            self.note.as_deref(),
        ])
    }
}

/// The recent tip `candidate` repeats: same key, sent within
/// [`TIP_DUPLICATE_WINDOW_SECS`], by anyone, and NOT dismissed (a tip the
/// interpreter hid may be sent again).
pub fn find_recent_duplicate<'a>(
    tips: &'a [TipDto],
    candidate: &ValidTip,
    now: DateTime<Utc>,
) -> Option<&'a TipDto> {
    let since = now.checked_sub_signed(Duration::seconds(TIP_DUPLICATE_WINDOW_SECS))?;
    let key = candidate.duplicate_key();
    tips.iter().find(|tip| {
        tip.dismissed_at.is_none() && tip.created_at > since && tip.duplicate_key() == key
    })
}

/// A service date as stored and sent: `YYYY-MM-DD`.
pub fn service_date_string(date: NaiveDate) -> String {
    date.format("%Y-%m-%d").to_string()
}

/// Spec §9.3: not dismissed, of today's service date, younger than
/// [`TIP_ACTIVE_WINDOW_HOURS`].
pub fn is_active(tip: &TipDto, today: NaiveDate, now: DateTime<Utc>) -> bool {
    let Some(since) = now.checked_sub_signed(Duration::hours(TIP_ACTIVE_WINDOW_HOURS)) else {
        return false;
    };
    tip.dismissed_at.is_none()
        && tip.service_date == service_date_string(today)
        && tip.created_at > since
}
```

```rust
//! Šepkár tips repository (#852 spec §9.2): plain CRUD over
//! `interpreter_tips`. Every rule that needs a clock (the active window, the
//! duplicate window, "today") lives in the caller, which passes the dates.
//! Refusals are typed (`repository-error-pattern.md`): an unknown id is
//! `NotFound` (404), restoring a tip of another day is `Conflict` (409).

use super::util::RepositoryError;
use super::Repository;
use crate::entities::interpreter_tip;
use chrono::{DateTime, NaiveDate, Utc};
use presenter_core::interpreter_tips::{service_date_string, TipDto};
use sea_orm::{
    ActiveModelTrait, ColumnTrait, EntityTrait, IntoActiveModel, NotSet, QueryFilter,
    QueryOrder, Set, TransactionTrait,
};
use tracing::instrument;

/// A validated tip plus its audit fields, ready to insert.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct NewInterpreterTip {
    pub service_date: NaiveDate,
    pub source_term: Option<String>,
    pub target_term: Option<String>,
    pub note: Option<String>,
    pub sender_name: String,
    pub sender_ip: String,
    pub user_agent: Option<String>,
    pub created_at: DateTime<Utc>,
}

const TIP_NOT_FOUND: &str = "Tip neexistuje.";

impl Repository {
    #[instrument(skip_all)]
    pub async fn insert_interpreter_tip(&self, tip: NewInterpreterTip) -> anyhow::Result<TipDto> {
        let inserted = interpreter_tip::ActiveModel {
            id: NotSet,
            service_date: Set(service_date_string(tip.service_date)),
            source_term: Set(tip.source_term),
            target_term: Set(tip.target_term),
            note: Set(tip.note),
            sender_name: Set(tip.sender_name),
            sender_ip: Set(tip.sender_ip),
            user_agent: Set(tip.user_agent),
            created_at: Set(tip.created_at.into()),
            dismissed_at: Set(None),
        }
        .insert(&self.db)
        .await?;
        Ok(tip_from_model(inserted))
    }

    /// Every tip of one service date, newest first — ordered by id, which
    /// follows insertion, never by a stored timestamp string.
    pub async fn list_interpreter_tips_on(&self, service_date: NaiveDate) -> anyhow::Result<Vec<TipDto>> {
        let models = interpreter_tip::Entity::find()
            .filter(interpreter_tip::Column::ServiceDate.eq(service_date_string(service_date)))
            .order_by_desc(interpreter_tip::Column::Id)
            .all(&self.db)
            .await?;
        Ok(models.into_iter().map(tip_from_model).collect())
    }

    /// Hide one tip. Idempotent: a hidden tip keeps its first `dismissed_at`.
    #[instrument(skip_all)]
    pub async fn dismiss_interpreter_tip(&self, id: i64, at: DateTime<Utc>) -> anyhow::Result<TipDto> {
        let model = self.interpreter_tip_by_id(id).await?;
        if model.dismissed_at.is_some() {
            return Ok(tip_from_model(model));
        }
        let mut active = model.into_active_model();
        active.dismissed_at = Set(Some(at.into()));
        Ok(tip_from_model(active.update(&self.db).await?))
    }

    /// Undo a dismiss (the interpreter's 5 s "Späť"). A tip of another
    /// service date is `Conflict`.
    #[instrument(skip_all)]
    pub async fn restore_interpreter_tip(&self, id: i64, today: NaiveDate) -> anyhow::Result<TipDto> {
        let model = self.interpreter_tip_by_id(id).await?;
        if model.service_date != service_date_string(today) {
            return Err(
                RepositoryError::Conflict("Tento tip už nie je z dnešnej bohoslužby.").into(),
            );
        }
        if model.dismissed_at.is_none() {
            return Ok(tip_from_model(model));
        }
        let mut active = model.into_active_model();
        active.dismissed_at = Set(None);
        Ok(tip_from_model(active.update(&self.db).await?))
    }

    /// Hide the given tips in one transaction. Returns how many were still
    /// shown; a missing or already hidden id is skipped.
    #[instrument(skip_all)]
    pub async fn dismiss_interpreter_tips(&self, ids: &[i64], at: DateTime<Utc>) -> anyhow::Result<u64> {
        let keys: Vec<i32> = ids.iter().filter_map(|id| i32::try_from(*id).ok()).collect();
        if keys.is_empty() {
            return Ok(0);
        }
        let txn = self.db.begin().await?;
        let models = interpreter_tip::Entity::find()
            .filter(interpreter_tip::Column::Id.is_in(keys))
            .filter(interpreter_tip::Column::DismissedAt.is_null())
            .all(&txn)
            .await?;
        let count = models.len() as u64;
        for model in models {
            let mut active = model.into_active_model();
            active.dismissed_at = Set(Some(at.into()));
            active.update(&txn).await?;
        }
        txn.commit().await?;
        Ok(count)
    }

    /// Delete every tip whose service date is before `cutoff` (retention).
    #[instrument(skip_all)]
    pub async fn prune_interpreter_tips_before(&self, cutoff: NaiveDate) -> anyhow::Result<u64> {
        let result = interpreter_tip::Entity::delete_many()
            .filter(interpreter_tip::Column::ServiceDate.lt(service_date_string(cutoff)))
            .exec(&self.db)
            .await?;
        Ok(result.rows_affected)
    }

    async fn interpreter_tip_by_id(&self, id: i64) -> anyhow::Result<interpreter_tip::Model> {
        // An out-of-i32 id can never be a row: refuse, never wrap into another
        // row (stream-graphics.md i32/i64 rule).
        let key = i32::try_from(id).map_err(|_| RepositoryError::NotFound(TIP_NOT_FOUND))?;
        interpreter_tip::Entity::find_by_id(key)
            .one(&self.db)
            .await?
            .ok_or(RepositoryError::NotFound(TIP_NOT_FOUND).into())
    }
}

fn tip_from_model(model: interpreter_tip::Model) -> TipDto {
    TipDto {
        id: i64::from(model.id),
        service_date: model.service_date,
        source_term: model.source_term,
        target_term: model.target_term,
        note: model.note,
        sender_name: model.sender_name,
        created_at: model.created_at.with_timezone(&Utc),
        dismissed_at: model.dismissed_at.map(|at| at.with_timezone(&Utc)),
    }
}
```

```rust
//! accepted tips per `TIP_RATE_WINDOW_SECS` per (sender IP, sender name) —

use std::collections::{HashMap, VecDeque};
use tokio::time::{Duration, Instant};

/// Which limit refused a tip.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(super) enum RateScope {
    Sender,
    Overall,
}

impl RateScope {
    pub(super) fn as_str(self) -> &'static str {
        match self {
            Self::Sender => "sender",
            Self::Overall => "overall",
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(super) enum RateVerdict {
    Allowed,
    Refused {
        scope: RateScope,
        retry_after_secs: u64,
        /// `Some(n)` = log this refusal now (one WARN per window per key);
        /// `n` refusals were suppressed since the previous WARN.
        warn: Option<u32>,
    },
}

/// One key's accepted instants and its WARN bookkeeping.
#[derive(Debug, Default)]
struct Window {
    accepted: VecDeque<Instant>,
    last_warn: Option<Instant>,
    suppressed: u32,
}

impl Window {
    fn forget_older_than(&mut self, now: Instant, window: Duration) {
        while self
            .accepted
            .front()
            .is_some_and(|at| now.saturating_duration_since(*at) >= window)
        {
            self.accepted.pop_front();
        }
    }

    /// Whole seconds (≥ 1) until the oldest accepted instant leaves.
    fn retry_after_secs(&self, now: Instant, window: Duration) -> u64 {
        let wait = self.accepted.front().map_or(Duration::ZERO, |oldest| {
            (*oldest + window).saturating_duration_since(now)
        });
        (wait.as_secs() + u64::from(wait.subsec_nanos() > 0)).max(1)
    }

    fn warn_now(&mut self, now: Instant, window: Duration) -> Option<u32> {
        if self
            .last_warn
            .is_some_and(|at| now.saturating_duration_since(at) < window)
        {
            self.suppressed = self.suppressed.saturating_add(1);
            return None;
        }
        self.last_warn = Some(now);
        Some(std::mem::take(&mut self.suppressed))
    }

    fn is_idle(&self, now: Instant, window: Duration) -> bool {
        self.accepted.is_empty()
            && self
                .last_warn
                .is_none_or(|at| now.saturating_duration_since(at) >= window)
    }
}

/// The limiter behind `InterpreterTipsState` (one per `AppState`).
#[derive(Debug)]
pub(super) struct TipRateLimiter {
    window: Duration,
    per_sender: usize,
    overall_cap: usize,
    senders: HashMap<String, Window>,
    overall: Window,
}

impl TipRateLimiter {
    pub(super) fn new() -> Self {
        Self {
            window: Duration::from_secs(TIP_RATE_WINDOW_SECS),
            per_sender: TIP_RATE_PER_SENDER,
            overall_cap: TIP_RATE_OVERALL,
            senders: HashMap::new(),
            overall: Window::default(),
        }
    }

    /// Count a tip that is about to be stored, or refuse it. A refused tip
    /// is never counted.
    pub(super) fn check(&mut self, client_ip: &str, sender_name: &str, now: Instant) -> RateVerdict {
        let window = self.window;
        self.senders.retain(|_, sender| {
            sender.forget_older_than(now, window);
            !sender.is_idle(now, window)
        });
        self.overall.forget_older_than(now, window);
        let sender = self
            .senders
            .entry(sender_key(client_ip, sender_name))
            .or_default();
        if sender.accepted.len() >= self.per_sender {
            return RateVerdict::Refused {
                scope: RateScope::Sender,
                retry_after_secs: sender.retry_after_secs(now, window),
                warn: sender.warn_now(now, window),
            };
        }
        if self.overall.accepted.len() >= self.overall_cap {
            return RateVerdict::Refused {
                scope: RateScope::Overall,
                retry_after_secs: self.overall.retry_after_secs(now, window),
                warn: self.overall.warn_now(now, window),
            };
        }
        sender.accepted.push_back(now);
        self.overall.accepted.push_back(now);
        RateVerdict::Allowed
    }
}

fn sender_key(client_ip: &str, sender_name: &str) -> String {
    format!("{client_ip}\u{1f}{}", sender_name.to_lowercase())
}
```

```rust
//! repository and the live hub.
//!

//!   limit → insert → publish. A 422 or a duplicate never uses a rate slot.

                sender_name,

                retry_after_secs,
                suppressed,
                "šepkár tip refused by the rate limit"
            );
        }
        Err(match scope {
            RateScope::Sender => TipRefusal::SenderRateLimited { retry_after_secs },
            RateScope::Overall => TipRefusal::OverallRateLimited { retry_after_secs },
        })
    }

    /// `POST /interpreter/tips/{id}/dismiss` — idempotent.
    pub(crate) async fn dismiss_interpreter_tip(&self, id: i64, client_ip: &str) -> anyhow::Result<TipDto> {
        let now = self.interpreter_tips.clock().now();
        let tip = self.repository.dismiss_interpreter_tip(id, now).await?;
        log_tip("dismiss", &tip, client_ip, false);
        self.publish_interpreter_tips_logged().await;
        Ok(tip)
    }

    /// `POST /interpreter/tips/{id}/restore` — the 5 s undo.
    pub(crate) async fn restore_interpreter_tip(&self, id: i64, client_ip: &str) -> anyhow::Result<TipDto> {
        let clock = self.interpreter_tips.clock();
        let today = clock.service_date(clock.now());
        let tip = self.repository.restore_interpreter_tip(id, today).await?;
        log_tip("restore", &tip, client_ip, false);
        self.publish_interpreter_tips_logged().await;
        Ok(tip)
    }

    /// `POST /interpreter/tips/dismiss-all` — hides every active tip.
    pub(crate) async fn dismiss_all_interpreter_tips(&self, client_ip: &str) -> anyhow::Result<u64> {
        let snapshot = self.tips_snapshot().await?;
        let active = ids(&snapshot.active());
        let dismissed = self
            .repository
            .dismiss_interpreter_tips(&active, snapshot.now)
            .await?;
        tracing::info!(
            target: "presenter::interpreter::tip",
            action = "dismiss_all",
            dismissed,
            client_ip,
            "šepkár tips hidden"
        );
        self.publish_interpreter_tips_logged().await;
        Ok(dismissed)
    }

    /// Publish the full active list (newest first, capped) and remember its
    /// ids. Serialized: the last publish always reflects the last commit.
    pub(crate) async fn publish_interpreter_tips(&self) -> anyhow::Result<()> {
        let _serialized = self.interpreter_tips.publish_lock.lock().await;
        let snapshot = self.tips_snapshot().await?;
        let mut tips = snapshot.active();
        tips.truncate(TIP_LIVE_LIST_CAP);
        self.interpreter_tips.set_published_ids(ids(&tips));
        self.live_hub.publish(LiveEvent::InterpreterTips {
            service_date: service_date_string(snapshot.today),
            tips,
        });
        Ok(())
    }

    async fn publish_interpreter_tips_logged(&self) {
        if let Err(err) = self.publish_interpreter_tips().await {
            tracing::warn!(
                target: "presenter::interpreter::tip",
                ?err,
                "publishing the šepkár tips failed — clients resync on reconnect"
            );
        }
    }

    /// The minute boundary check: re-publish when midnight or the 4 h window
    /// changed the active list. Reads nothing while the last list was empty.
    pub(crate) async fn interpreter_tips_tick(&self) -> anyhow::Result<()> {
        let published = self.interpreter_tips.published_ids();
        if published.is_empty() {
            return Ok(());
        }
        let snapshot = self.tips_snapshot().await?;
        let mut active = snapshot.active();
        active.truncate(TIP_LIVE_LIST_CAP);
        if ids(&active) != published {
            self.publish_interpreter_tips().await?;
        }
        Ok(())
    }

    /// Delete tips whose service date is more than `TIP_RETENTION_DAYS` ago.
    pub(crate) async fn prune_interpreter_tips(&self) -> anyhow::Result<u64> {
        let clock = self.interpreter_tips.clock();
        let today = clock.service_date(clock.now());
        let Some(cutoff) = today.checked_sub_signed(chrono::Duration::days(TIP_RETENTION_DAYS))
        else {
            return Ok(0);
        };
        let pruned = self.repository.prune_interpreter_tips_before(cutoff).await?;
        if pruned > 0 {
            tracing::info!(
                target: "presenter::interpreter::tip",
                pruned,
                retention_days = TIP_RETENTION_DAYS,
                "old šepkár tips deleted"
            );
        }
        Ok(pruned)
    }

    /// One minute of the background task: retention once per service date
    /// (one attempt, failed or not — a broken DB must not WARN every minute),
    /// then the boundary check (failures WARN on #484 power-of-two streaks).
    async fn interpreter_tips_maintenance(&self, memory: &mut TipMaintenance) {
        let clock = self.interpreter_tips.clock();
        let today = clock.service_date(clock.now());
        if memory.last_prune != Some(today) {
            memory.last_prune = Some(today);
            if let Err(err) = self.prune_interpreter_tips().await {
                tracing::warn!(
                    target: "presenter::interpreter::tip",
                    ?err,
                    "šepkár tip retention failed — next try tomorrow"
                );
            }
        }
        match self.interpreter_tips_tick().await {
            Ok(()) => {
                if memory.tick_failures > 0 {
                    tracing::info!(
                        target: "presenter::interpreter::tip",
                        failures = memory.tick_failures,
                        "šepkár tip boundary check recovered"
                    );
                }
                memory.tick_failures = 0;
            }
            Err(err) => {
                memory.tick_failures = memory.tick_failures.saturating_add(1);
                if memory.tick_failures.is_power_of_two() {
                    tracing::warn!(
                        target: "presenter::interpreter::tip",
                        ?err,
                        failures = memory.tick_failures,
                        "šepkár tip boundary check failed"
                    );
                }
            }
        }
    }

    /// The minute task (spec §9.5 boundary + §9.9 retention). The first
    /// publish seeds `published`, so a restart mid-service still sends the
    /// boundary event for the tips already on screen.
    pub(super) fn spawn_interpreter_tips_task(&self) {
        let state = self.clone();
        tokio::spawn(async move {
            state.publish_interpreter_tips_logged().await;
            let mut memory = TipMaintenance::default();
            let mut ticker = interval(Duration::from_secs(60));
            ticker.set_missed_tick_behavior(MissedTickBehavior::Delay);
            loop {
                ticker.tick().await;
                state.interpreter_tips_maintenance(&mut memory).await;
            }
        });
    }
}

        offset: chrono::FixedOffset,
    }

    impl ManualTipClock {
        /// `local` is RFC 3339 with the zone, e.g. `2026-10-18T19:42:00+02:00`.
        pub(crate) fn at(local: &str) -> Arc<Self> {
            let parsed = DateTime::parse_from_rfc3339(local).expect("RFC 3339 time");
            Arc::new(Self {
                now: Mutex::new(parsed.with_timezone(&Utc)),
                offset: *parsed.offset(),
            })
        }

        pub(crate) fn advance(&self, by: chrono::Duration) {
            let mut now = self.now.lock().unwrap_or_else(PoisonError::into_inner);
            *now += by;
        }
    }

    impl TipClock for ManualTipClock {
        fn now(&self) -> DateTime<Utc> {
            *self.now.lock().unwrap_or_else(PoisonError::into_inner)
        }

        fn service_date(&self, at: DateTime<Utc>) -> NaiveDate {
            at.with_timezone(&self.offset).date_naive()
        }
    }

    /// The last `InterpreterTips` event waiting in `rx`, skipping every other
    /// event (heartbeats interleave); `None` if there is none.
    pub(crate) fn last_tips_event(
        rx: &mut broadcast::Receiver<LiveEvent>,
    ) -> Option<(String, Vec<TipDto>)> {
        let mut last = None;
        while let Ok(event) = rx.try_recv() {
            if let LiveEvent::InterpreterTips { service_date, tips } = event {
                last = Some((service_date, tips));
            }
        }
        last
    }

    impl AppState {
        pub(crate) fn set_interpreter_tip_clock(&self, clock: Arc<dyn TipClock>) {
            *self
                .interpreter_tips
                .clock
                .write()
                .unwrap_or_else(PoisonError::into_inner) = clock;
        }
    }
```

```rust
//! Šepkár tips REST API (#852 spec §9.4), merged with one
//! `.merge(interpreter_tips::router())` in `router.rs`:
//! `GET|POST /interpreter/tips`, `POST /interpreter/tips/dismiss-all`,
//! `POST /interpreter/tips/{id}/dismiss`, `POST /interpreter/tips/{id}/restore`.
//!
//! Repository refusals (unknown id 404, another day's restore 409) map
//! through the central `From<anyhow::Error> for AppError`; the state-layer
//! `TipRefusal` maps here: 422 with the Slovak rule, 429 with `Retry-After`.
//! The client IP follows the #793 rule (`integrations::extract_client_ip`).

use super::AppError;
use crate::state::interpreter_tips::{TipOrigin, TipRefusal, TipScope};
use crate::state::AppState;
use axum::{
    extract::{ConnectInfo, Path, Query, State},
    http::{header::USER_AGENT, HeaderMap, StatusCode},
    routing::{get, post},
    Extension, Json, Router,
};
use presenter_core::interpreter_tips::{
    clean_user_agent, CreateTipResponse, DismissAllResponse, NewTipRequest, TipDto, TipsList,
};
use serde::Deserialize;
use std::net::SocketAddr;
use tracing::instrument;

/// The tips sub-router.
pub fn router() -> Router<AppState> {
    Router::new()
        .route("/interpreter/tips", get(list_tips).post(create_tip))
        .route("/interpreter/tips/dismiss-all", post(dismiss_all))
        .route("/interpreter/tips/{id}/dismiss", post(dismiss_tip))
        .route("/interpreter/tips/{id}/restore", post(restore_tip))
}

#[derive(Debug, Default, Deserialize)]
pub(super) struct TipsQuery {
    #[serde(default)]
    scope: TipScope,
}

/// The socket peer; optional so a router served without connect-info
/// (tests) still answers.
type Peer = Option<Extension<ConnectInfo<SocketAddr>>>;

fn client_ip(headers: &HeaderMap, peer: Peer) -> String {
    super::integrations::extract_client_ip(
        headers,
        peer.map(|Extension(ConnectInfo(addr))| addr),
    )
}

fn origin(headers: &HeaderMap, peer: Peer) -> TipOrigin {
    let user_agent = headers
        .get(USER_AGENT)
        .and_then(|value| value.to_str().ok())
        .and_then(clean_user_agent);
    TipOrigin {
        client_ip: client_ip(headers, peer),
        user_agent,
    }
}

/// `TipRefusal` → 422 / 429 + `Retry-After`; everything else → the central
/// mapping (404 / 409 / 500).
fn map_tip_error(err: anyhow::Error) -> AppError {
    let Some((message, retry_after)) = err
        .downcast_ref::<TipRefusal>()
        .map(|refusal| (refusal.to_string(), refusal.retry_after_secs()))
    else {
        return AppError::from(err);
    };
    match retry_after {
        None => AppError::unprocessable(message),
        Some(secs) => AppError {
            status: StatusCode::TOO_MANY_REQUESTS,
            error: anyhow::anyhow!(message),
            retry_after: Some(secs),
        },
    }
}

#[instrument(skip_all)]
pub(super) async fn list_tips(
    State(state): State<AppState>,
    Query(query): Query<TipsQuery>,
) -> Result<Json<TipsList>, AppError> {
    Ok(Json(state.interpreter_tips_list(query.scope).await?))
}

#[instrument(skip_all)]
pub(super) async fn create_tip(
    State(state): State<AppState>,
    headers: HeaderMap,
    peer: Peer,
    Json(request): Json<NewTipRequest>,
) -> Result<(StatusCode, Json<CreateTipResponse>), AppError> {
    let created = state
        .create_interpreter_tip(&request, origin(&headers, peer))
        .await
        .map_err(map_tip_error)?;
    let status = if created.duplicate {
        StatusCode::OK
    } else {
        StatusCode::CREATED
    };
    Ok((
        status,
        Json(CreateTipResponse {
            tip: created.tip,
            duplicate: created.duplicate,
        }),
    ))
}

#[instrument(skip_all)]
pub(super) async fn dismiss_tip(
    State(state): State<AppState>,
    headers: HeaderMap,
    peer: Peer,
    Path(id): Path<i64>,
) -> Result<Json<TipDto>, AppError> {
    let ip = client_ip(&headers, peer);
    Ok(Json(state.dismiss_interpreter_tip(id, &ip).await?))
}

#[instrument(skip_all)]
pub(super) async fn restore_tip(
    State(state): State<AppState>,
    headers: HeaderMap,
    peer: Peer,
    Path(id): Path<i64>,
) -> Result<Json<TipDto>, AppError> {
    let ip = client_ip(&headers, peer);
    Ok(Json(state.restore_interpreter_tip(id, &ip).await?))
}

#[instrument(skip_all)]
pub(super) async fn dismiss_all(
    State(state): State<AppState>,
    headers: HeaderMap,
    peer: Peer,
) -> Result<Json<DismissAllResponse>, AppError> {
    let ip = client_ip(&headers, peer);
    let dismissed = state.dismiss_all_interpreter_tips(&ip).await?;
    Ok(Json(DismissAllResponse { dismissed }))
}
```

```markdown
- **One source for the rules:** core `interpreter_tips.rs` (limits, `clean_text`, `validate_tip`,
  `is_active`, `find_recent_duplicate`). The server is the only validator; the pages read the same
  constants for counters but never block a send.

  presentations + libraries — never add the table to `state/sync.rs`. The dev deploy copies prod's
  DB (tips included) to dev.
- **Dates:** `service_date` is TEXT `YYYY-MM-DD` (the server's LOCAL date, `TipClock`). Filter by
  equality / lexical order (active list, duplicate check, retention `service_date < today − 30`);
  compare timestamps in Rust, never in SQL.
- **Refusals:** validation + rate limits are decided in the state layer → `TipRefusal`, mapped in
  `router/interpreter_tips.rs::map_tip_error` (422 Slovak rule / 429 + `Retry-After`). Unknown id
  (404) and another day's restore (409) are `RepositoryError` through the central mapping. Never
  route the state refusals through `RepositoryError`.
- **Create order:** validate → duplicate → rate limit → insert → publish. A 422 or a duplicate never
  uses a rate slot (pinned by `invalid_tips_are_422_with_the_slovak_rule`).
- **Duplicate:** the pair (or the note, when there is no pair), lower-cased, whitespace collapsed,
  sent within 2 min by anyone and NOT dismissed → 200 + `duplicate: true` + the earlier tip; no row,
  no event. A hidden tip may be sent again.
- **Rate limit:** exact sliding window per (client IP, lower-cased name) 5 / 60 s + 30 / 60 s overall,
  tokio `Instant`, in memory (reset on restart). One WARN per 60 s per key with `suppressed`.
- **Live event:** `InterpreterTips` = FULL active list, newest first, capped at 20, after every write.
  Publishes hold `publish_lock` (two writes could otherwise end on the older list). GET is not capped.
- **Boundary + retention:** one minute task from `spawn_background_tasks` (never in validate mode):
  retention once per service date, then the tick re-publishes when the active ids changed. The tick
  reads nothing while the last published list is empty; the task seeds it at start (restart).
- **Clock in tests:** `test_support::ManualTipClock::at("…+02:00")` + `set_interpreter_tip_clock`;
```

```rust
/// Drops a resync answer that something newer overtook (the stage's
/// `StageSyncGeneration` idea): [`FetchGuard::begin`] a fetch, call
/// [`FetchGuard::note_newer`] on every live list or own write, and apply the
/// answer only if [`FetchGuard::accepts`] its ticket. Only the newest fetch

    generation: u64,

impl FetchGuard {
    pub fn begin(&mut self) -> u64 {

    }

    pub fn note_newer(&mut self) {
        self.generation = self.generation.wrapping_add(1);
    }

    pub fn accepts(&self, ticket: u64) -> bool {
        self.generation == ticket
    }
}
```

```rust
//! Presence-free live socket for read-only pages (#852: the interpreter
//! tablet and the šepkár page). Unlike `use_live_websocket` it hands EVERY
//! frame to `on_event` synchronously, in arrival order (#793: a latest-value
//! slot coalesces a burst and loses events); unlike the stage socket it sends
//! no presence, so these pages never count as stage displays.
//!
//! Liveness (A+B spec §6.7): the hub heartbeats every 1.5 s. A socket is
//! "connected" from its first frame; one silent for 5 s is dropped and
//! reopened (backoff 1 s doubling to 10 s); a page visible again after more
//! than 30 s hidden reconnects at once (iOS suspends sockets). `connects`
//! counts sockets that delivered a frame, so a page resyncs on every
//! (re)connect — the hub never replays.

use gloo_net::websocket::{futures::WebSocket, Message};
use gloo_timers::callback::Timeout;
use leptos::prelude::*;
use presenter_core::LiveEvent;
use std::cell::Cell;
use std::rc::Rc;
use wasm_bindgen::prelude::*;
use wasm_bindgen::JsCast;

const INITIAL_RECONNECT_MS: u32 = 1_000;
const MAX_RECONNECT_MS: u32 = 10_000;
const CHECK_INTERVAL_MS: u32 = 500;
const SILENT_SOCKET_MS: f64 = 5_000.0;
const HIDDEN_RECONNECT_MS: f64 = 30_000.0;

/// Called synchronously for every live event, in arrival order.
pub type LiveEventHandler = Rc<dyn Fn(LiveEvent)>;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PassiveWsState {
    Connecting,
    Connected,
    Reconnecting,
}

impl PassiveWsState {
    /// The `data-ws` value the pages expose (and the E2E reads).
    pub fn as_str(self) -> &'static str {
        match self {
            Self::Connecting => "connecting",
            Self::Connected => "connected",
            Self::Reconnecting => "reconnecting",
        }
    }
}

#[derive(Clone, Copy)]
pub struct PassiveWsHandle {
    pub state: ReadSignal<PassiveWsState>,
    /// Sockets that delivered a frame so far; a change = resync now.
    pub connects: ReadSignal<u32>,
}

/// Shared by the read loop, the reconnect timer and the visibility listener.
struct Shared {
    surface: &'static str,
    on_event: LiveEventHandler,
    set_state: WriteSignal<PassiveWsState>,
    set_connects: WriteSignal<u32>,
    last_frame_at: Cell<f64>,
    reconnect_delay: Cell<u32>,
    hidden_since: Cell<Option<f64>>,
    force_reconnect: Cell<bool>,
}

pub fn use_passive_websocket(surface: &'static str, on_event: LiveEventHandler) -> PassiveWsHandle {
    let (state, set_state) = signal(PassiveWsState::Connecting);
    let (connects, set_connects) = signal(0_u32);
    let shared = Rc::new(Shared {
        surface,
        on_event,
        set_state,
        set_connects,
        last_frame_at: Cell::new(js_sys::Date::now()),
        reconnect_delay: Cell::new(INITIAL_RECONNECT_MS),
        hidden_since: Cell::new(None),
        force_reconnect: Cell::new(false),
    });
    watch_visibility(Rc::clone(&shared));
    spawn_connection(shared);
    PassiveWsHandle { state, connects }
}

fn spawn_connection(shared: Rc<Shared>) {
    leptos::task::spawn_local(async move {
        match WebSocket::open(&super::ws_url(shared.surface)) {
            Ok(socket) => {
                use futures_util::StreamExt;
                let (_write, read) = socket.split();
                shared.last_frame_at.set(js_sys::Date::now());
                shared.force_reconnect.set(false);
                read_until_dead(read, &shared).await;
            }
            Err(err) => leptos::logging::log!("{} ws: open failed: {err:?}", shared.surface),
        }
        shared.set_state.set(PassiveWsState::Reconnecting);
        let delay = shared.reconnect_delay.get();
        shared
            .reconnect_delay
            .set((delay * 2).min(MAX_RECONNECT_MS));
        Timeout::new(delay, move || spawn_connection(shared)).forget();
    });
}

/// Read until the socket closes, errors, goes silent for 5 s or the page
/// asks for a fresh socket (back from a long hide).
async fn read_until_dead(mut read: futures_util::stream::SplitStream<WebSocket>, shared: &Rc<Shared>) {
    use futures_util::future::{select, Either};
    use futures_util::StreamExt;

    let mut opened = false;
    loop {
        let next = read.next();
        let tick = gloo_timers::future::TimeoutFuture::new(CHECK_INTERVAL_MS);
        futures_util::pin_mut!(next, tick);
        match select(next, tick).await {
            Either::Left((Some(Ok(Message::Text(text))), _)) => {
                shared.last_frame_at.set(js_sys::Date::now());
                if !opened {
                    opened = true;
                    shared.reconnect_delay.set(INITIAL_RECONNECT_MS);
                    shared.set_state.set(PassiveWsState::Connected);
                    shared.set_connects.update(|n| *n += 1);
                }
                if let Ok(event) = serde_json::from_str::<LiveEvent>(&text) {
                    (shared.on_event)(event);
                }
            }
            Either::Left((Some(Ok(Message::Bytes(_))), _)) => {}
            Either::Left((Some(Err(_)) | None, _)) => return,
            Either::Right(((), _)) => {
                let silent_for = js_sys::Date::now() - shared.last_frame_at.get();
                if shared.force_reconnect.replace(false) || silent_for >= SILENT_SOCKET_MS {
                    leptos::logging::log!(
                        "{} ws: silent for {silent_for:.0} ms — reconnecting",
                        shared.surface
                    );
                    return;
                }
            }
        }
    }
}

/// Remember when the page was hidden; back after more than 30 s → fresh
/// socket at the next check (≤ 0.5 s). The closure lives as long as the page.
fn watch_visibility(shared: Rc<Shared>) {
    let Some(document) = web_sys::window().and_then(|window| window.document()) else {
        return;
    };
    let doc = document.clone();
    let callback = Closure::<dyn FnMut()>::new(move || {
        let now = js_sys::Date::now();
        if doc.visibility_state() == web_sys::VisibilityState::Hidden {
            shared.hidden_since.set(Some(now));
            return;
        }
        if let Some(since) = shared.hidden_since.take() {
            if now - since > HIDDEN_RECONNECT_MS {
                shared.force_reconnect.set(true);
            }
        }
    });
    if document
        .add_event_listener_with_callback("visibilitychange", callback.as_ref().unchecked_ref())
        .is_err()
    {
        leptos::logging::log!("passive ws: visibilitychange listener not registered");
    }
    callback.forget();
}
```

```ts
/** A one-finger drag through CDP touch events (Playwright's touchscreen only taps). */
export async function touchDrag(
  page: Page,
  from: { x: number; y: number },
  to: { x: number; y: number },
  steps = 8,
): Promise<void> {
  const cdp = await page.context().newCDPSession(page);
  await cdp.send("Input.dispatchTouchEvent", {
    type: "touchStart",
    touchPoints: [{ x: from.x, y: from.y }],
  });
  for (let i = 1; i <= steps; i += 1) {
    await cdp.send("Input.dispatchTouchEvent", {
      type: "touchMove",
      touchPoints: [
        {
          x: from.x + ((to.x - from.x) * i) / steps,
          y: from.y + ((to.y - from.y) * i) / steps,
        },
      ],
    });
  }
  await cdp.send("Input.dispatchTouchEvent", { type: "touchEnd", touchPoints: [] });
  await cdp.detach();
}
```

```rust
//! The šepkár tips area (#852 spec §9.6): cards newest on top (pair large,
//! note smaller, "Peter · 19:42"), a 2 s highlight for a new card, ✕ or a
//! left swipe hides a card with a 5 s "Skryté — Späť" offer, "Skryť všetky"
//! after a confirm. Tips are immutable, so a keyed `<For>` by id is enough.

use crate::api::{self, interpreter_tips::TipsScope, ApiError};
use crate::state::interpreter::{
    fresh_ids, swipe_decision, swipe_offset, tip_meta, tip_pair, FetchGuard, SwipeDecision,
};
use gloo_timers::callback::Timeout;
use leptos::prelude::*;
use presenter_core::interpreter_tips::TipDto;
use std::collections::HashSet;
use wasm_bindgen::JsCast;
use web_sys::PointerEvent;

const UNDO_MS: u32 = 5_000;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
struct UndoOffer {
    id: i64,
    ticket: u64,
}

/// Client state of the tips area. `Copy` (signals only), shared by the page,
/// the socket handler and the cards.
#[derive(Clone, Copy)]
pub struct TipsModel {
    tips: RwSignal<Vec<TipDto>>,
    /// The first list arrived (`data-ready`, the E2E settle signal).
    ready: RwSignal<bool>,
    known: StoredValue<HashSet<i64>>,
    fresh: StoredValue<HashSet<i64>>,
    guard: StoredValue<FetchGuard>,
    undo_offer: RwSignal<Option<UndoOffer>>,
    undo_ticket: StoredValue<u64>,
    error: RwSignal<Option<String>>,
}

impl TipsModel {
    pub fn new() -> Self {
        Self {
            tips: RwSignal::new(Vec::new()),
            ready: RwSignal::new(false),
            known: StoredValue::new(HashSet::new()),
            fresh: StoredValue::new(HashSet::new()),
            guard: StoredValue::new(FetchGuard::default()),
            undo_offer: RwSignal::new(None),
            undo_ticket: StoredValue::new(0),
            error: RwSignal::new(None),
        }
    }

    /// Install a full active list (live event, resync or own write).
    fn install(self, list: Vec<TipDto>) {
        let first = !self.ready.get_untracked();
        let fresh = self.known.with_value(|known| fresh_ids(known, &list, first));
        self.known
            .update_value(|known| known.extend(list.iter().map(|tip| tip.id)));
        self.fresh.set_value(fresh);
        self.error.set(None);
        self.tips.set(list);
        self.ready.set(true);
    }

    /// A live `InterpreterTips` list: newer than any resync in flight.
    pub fn apply_live(self, list: Vec<TipDto>) {
        self.guard.update_value(FetchGuard::note_newer);
        self.install(list);
    }

    /// `GET /interpreter/tips` on load and after every (re)connect; dropped
    /// when a live list or an own write overtook it.
    pub fn resync(self) {
        let ticket = self
            .guard
            .try_update_value(FetchGuard::begin)
            .unwrap_or_default();
        leptos::task::spawn_local(async move {
            match api::interpreter_tips::list(TipsScope::Active).await {
                Ok(list) => {
                    if self.guard.with_value(|guard| guard.accepts(ticket)) {
                        self.install(list.tips);
                    }
                }
                Err(err) => leptos::logging::log!("interpreter: tips resync failed: {err}"),
            }
        });
    }

    fn is_fresh(self, id: i64) -> bool {
        self.fresh.with_value(|fresh| fresh.contains(&id))
    }

    /// ✕ / swipe: hide at once, tell the server, offer "Späť" for 5 s.
    fn dismiss(self, id: i64) {
        self.guard.update_value(FetchGuard::note_newer);
        self.tips.update(|tips| tips.retain(|tip| tip.id != id));
        let ticket = self.undo_ticket.get_value().wrapping_add(1);
        self.undo_ticket.set_value(ticket);
        self.undo_offer.set(Some(UndoOffer { id, ticket }));
        Timeout::new(UNDO_MS, move || {
            let current = self.undo_offer.try_get_untracked().flatten();
            if current.is_some_and(|offer| offer.ticket == ticket) {
                let _ = self.undo_offer.try_set(None);
            }
        })
        .forget();
        leptos::task::spawn_local(async move {
            if let Err(err) = api::interpreter_tips::dismiss(id).await {
                self.fail("Tip sa nepodarilo skryť", err);
            }
        });
    }

    fn undo_dismiss(self) {
        let Some(offer) = self.undo_offer.get_untracked() else {
            return;
        };
        self.undo_offer.set(None);
        leptos::task::spawn_local(async move {
            match api::interpreter_tips::restore(offer.id).await {
                Ok(_) => self.resync(),
                Err(err) => self.fail("Tip sa nepodarilo vrátiť", err),
            }
        });
    }

    fn dismiss_all(self) {
        let confirmed = crate::utils::window::window()
            .confirm_with_message("Skryť všetky tipy?")
            .unwrap_or(false);
        if !confirmed {
            return;
        }
        leptos::task::spawn_local(async move {
            if let Err(err) = api::interpreter_tips::dismiss_all().await {
                self.fail("Tipy sa nepodarilo skryť", err);
            }
        });
    }

    fn fail(self, what: &str, err: ApiError) {
        let message = match err {
            ApiError::Status(_, detail) => format!("{what}: {detail}"),
            other => format!("{what} — server je nedostupný ({other})."),
        };
        self.error.set(Some(message));
        self.resync();
    }
}

impl Default for TipsModel {
    fn default() -> Self {
        Self::new()
    }
}

/// True when the pointer went down on the card's ✕ — that is a tap on the
/// button, never the start of a swipe.
fn starts_on_dismiss_button(ev: &PointerEvent) -> bool {
    ev.target()
        .and_then(|target| target.dyn_into::<web_sys::Element>().ok())
        .and_then(|el| el.closest("[data-role=\"interpreter-tip-dismiss\"]").ok().flatten())
        .is_some()
}

#[component]
fn TipCard(tip: TipDto, model: TipsModel) -> impl IntoView {
    let id = tip.id;
    let pair = tip_pair(&tip);
    let note = tip.note.clone();
    let meta = tip_meta(&tip, &chrono::Local);
    let is_new = model.is_fresh(id);
    // Swipe: where the pointer went down, and how far the card follows it.
    // No pointer capture: it would retarget the ✕ button's click.
    let start = StoredValue::new(None::<(f64, f64)>);
    let offset = RwSignal::new(0.0_f64);
    let on_down = move |ev: PointerEvent| {
        if !starts_on_dismiss_button(&ev) {
            start.set_value(Some((f64::from(ev.client_x()), f64::from(ev.client_y()))));
        }
    };
    let on_move = move |ev: PointerEvent| {
        if let Some((x, _)) = start.get_value() {
            offset.set(swipe_offset(f64::from(ev.client_x()) - x));
        }
    };
    let on_up = move |ev: PointerEvent| {
        let Some((x, y)) = start.get_value() else {
            return;
        };
        start.set_value(None);
        let dx = f64::from(ev.client_x()) - x;
        let dy = f64::from(ev.client_y()) - y;
        match swipe_decision(dx, dy) {
            SwipeDecision::Dismiss => model.dismiss(id),
            SwipeDecision::SnapBack => offset.set(0.0),
        }
    };
    let on_cancel = move |_: PointerEvent| {
        start.set_value(None);
        offset.set(0.0);
    };
    let style = move || format!("transform: translateX({}px)", offset.get());
    view! {
        <li
            class="interpreter-tip"
            data-role="interpreter-tip"
            data-tip-id=id.to_string()
            data-new=is_new.to_string()
            style=style
            on:pointerdown=on_down
            on:pointermove=on_move
            on:pointerup=on_up
            on:pointercancel=on_cancel
            on:pointerleave=on_cancel
        >
            {pair.map(|text| view! {
                <span class="interpreter-tip__pair" data-role="interpreter-tip-pair">{text}</span>
            })}
            {note.map(|text| view! {
                <span class="interpreter-tip__note" data-role="interpreter-tip-note">{text}</span>
            })}
            <span class="interpreter-tip__meta" data-role="interpreter-tip-meta">{meta}</span>
            <button
                type="button"
                class="interpreter-tip__dismiss"
                data-role="interpreter-tip-dismiss"
                aria-label="Skryť tip"
                on:click=move |_| model.dismiss(id)
            >
                "✕"
            </button>
        </li>
    }
}
```

```rust
//! Šepkár page `/ui/sepkar` (#852 spec §9.7): anyone who can open Presenter
//! sends the interpreter a short tip — a word → its translation, or a note.
//! Phone first; on a laptop the "Dnes" list sits beside the form. The server
//! is the only validator: its Slovak 422 / 429 text shows inline and the
//! fields keep their content. The name is remembered per device
//! (`state::session`, non-throwing localStorage). The list refetches on every
//! `InterpreterTips` event and after every (re)connect.

use crate::api::{self, interpreter_tips::TipsScope, ApiError};
use crate::components::version_label::VersionLabel;
use crate::state::interpreter::{note_counter, tip_meta, tip_pair, FetchGuard, SepkarRowState};
use crate::state::session;
use crate::ws::passive::{use_passive_websocket, LiveEventHandler};
use gloo_timers::callback::Timeout;
use leptos::html::Input;
use leptos::prelude::*;
use presenter_core::interpreter_tips::{NewTipRequest, TipDto, TipsList};
use presenter_core::LiveEvent;
use std::rc::Rc;
use web_sys::KeyboardEvent;

const NAME_KEY: &str = "sepkarName";
const NOTICE_MS: u32 = 4_000;

/// The form + the "Dnes" list. `Copy` (signals only).
#[derive(Clone, Copy)]
struct SepkarForm {
    name: RwSignal<String>,
    source: RwSignal<String>,
    target: RwSignal<String>,
    note: RwSignal<String>,
    sending: RwSignal<bool>,
    error: RwSignal<Option<String>>,
    notice: RwSignal<Option<String>>,
    notice_ticket: StoredValue<u64>,
    today: RwSignal<TipsList>,
    today_guard: StoredValue<FetchGuard>,
}

fn optional(field: RwSignal<String>) -> Option<String> {
    let value = field.get_untracked();
    if value.trim().is_empty() {
        None
    } else {
        Some(value)
    }
}

impl SepkarForm {
    fn new() -> Self {
        Self {
            name: RwSignal::new(session::get_persistent(NAME_KEY).unwrap_or_default()),
            source: RwSignal::new(String::new()),
            target: RwSignal::new(String::new()),
            note: RwSignal::new(String::new()),
            sending: RwSignal::new(false),
            error: RwSignal::new(None),
            notice: RwSignal::new(None),
            notice_ticket: StoredValue::new(0),
            today: RwSignal::new(TipsList::default()),
            today_guard: StoredValue::new(FetchGuard::default()),
        }
    }

    fn request(self) -> NewTipRequest {
        NewTipRequest {
            sender_name: self.name.get_untracked(),
            source_term: optional(self.source),
            target_term: optional(self.target),
            note: optional(self.note),
        }
    }

    /// Refetch today's tips; only the newest request may land.
    fn reload_today(self) {
        let ticket = self
            .today_guard
            .try_update_value(FetchGuard::begin)
            .unwrap_or_default();
        leptos::task::spawn_local(async move {
            match api::interpreter_tips::list(TipsScope::Today).await {
                Ok(list) => {
                    if self.today_guard.with_value(|guard| guard.accepts(ticket)) {
                        self.today.set(list);
                    }
                }
                Err(err) => leptos::logging::log!("sepkar: today's tips failed: {err}"),
            }
        });
    }

    fn show_notice(self, text: String) {
        let ticket = self.notice_ticket.get_value().wrapping_add(1);
        self.notice_ticket.set_value(ticket);
        self.notice.set(Some(text));
        Timeout::new(NOTICE_MS, move || {
            if self.notice_ticket.try_get_value() == Some(ticket) {
                let _ = self.notice.try_set(None);
            }
        })
        .forget();
    }

    /// Send the tip. Success: notice, the three tip fields clear, focus back
    /// to "Slovo". Refusal / offline: the error inline, the fields untouched.
    fn send(self, source_input: NodeRef<Input>) {
        if self.sending.get_untracked() {
            return;
        }
        let request = self.request();
        self.sending.set(true);
        self.error.set(None);
        leptos::task::spawn_local(async move {
            let result = api::interpreter_tips::create(&request).await;
            self.sending.set(false);
            match result {
                Ok(response) => {
                    self.source.set(String::new());
                    self.target.set(String::new());
                    self.note.set(String::new());
                    let text = if response.duplicate {
                        "Tento tip už tlmočník má".to_string()
                    } else {
                        let time = response.tip.created_at.with_timezone(&chrono::Local);
                        format!("Odoslané {}", time.format("%H:%M"))
                    };
                    self.show_notice(text);
                    if let Some(input) = source_input.get_untracked() {
                        let _ = input.focus();
                    }
                    self.reload_today();
                }
                Err(ApiError::Status(_, detail)) => self.error.set(Some(detail)),
                Err(other) => self.error.set(Some(format!(
                    "Server je nedostupný — tip zostal v poliach, skús znova. ({other})"
                ))),
            }
        });
    }
}

fn focus(input: NodeRef<Input>) {
    if let Some(el) = input.get_untracked() {
        let _ = el.focus();
    }
}

#[component]
pub fn SepkarPage() -> impl IntoView {
    if let Some(body) = crate::utils::window::document_body() {
        let _ = body.set_attribute("class", "sepkar");
    }
    let form = SepkarForm::new();
    let source_input = NodeRef::<Input>::new();
    let target_input = NodeRef::<Input>::new();
    let on_event: LiveEventHandler = Rc::new(move |event| {
        if matches!(event, LiveEvent::InterpreterTips { .. }) {
            form.reload_today();
        }
    });
    let ws = use_passive_websocket("sepkar", on_event);
    Effect::new(move |_| {
        let _ = ws.connects.get();
        form.reload_today();
    });

    let on_name_key = move |ev: KeyboardEvent| {
        if ev.key() == "Enter" {
            ev.prevent_default();
            focus(source_input);
        }
    };
    let on_source_key = move |ev: KeyboardEvent| {
        if ev.key() == "Enter" {
            ev.prevent_default();
            focus(target_input);
        }

#[component]
fn SepkarRow(tip: TipDto, state: SepkarRowState) -> impl IntoView {
    let text = match (tip_pair(&tip), tip.note.clone()) {
        (Some(pair), Some(note)) => format!("{pair} — {note}"),
        (Some(pair), None) => pair,
        (None, Some(note)) => note,
        (None, None) => String::new(),
    };
    let meta = format!("{} · {}", tip_meta(&tip, &chrono::Local), state.label());
    view! {
        <li
            class="sepkar__row"
            data-role="sepkar-row"
            data-tip-id=tip.id.to_string()
            data-state=state.as_str()
        >
            <div class="sepkar__row-text">{text}</div>
            <div class="sepkar__row-meta">{meta}</div>
        </li>
    }
}
```
